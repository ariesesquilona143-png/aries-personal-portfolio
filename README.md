# Aries Esquilona — Personal Portfolio

A modern and aesthetic personal portfolio website made with **HTML5 and CSS3 only** for Activity 01: ALL OR NOTHING.

## Pages
- `index.html` — Home page and introduction
- `about.html` — Personal introduction, values, and interests
- `gallery.html` — Sample project gallery

## Folder structure
```text
aries-personal-portfolio/
├── index.html
├── about.html
├── gallery.html
├── css/
│   └── style.css
├── images/
└── README.md
```

## Technologies
- HTML5
- CSS3

No JavaScript, JavaScript libraries, or frameworks are used.

## Run locally
1. Download or extract the project folder.
2. Open `index.html` in a web browser.
3. Use the navigation links to visit the About and Projects pages.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository, for example `aries-personal-portfolio`.
2. Upload the contents of this folder to the repository's root. Make sure `index.html` is at the root level.
3. Open the repository's **Settings**.
4. Select **Pages** from the sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait for GitHub Pages to publish the site. Your public website link will appear in the Pages section.

## Before submitting
- Open the published website and test every navigation link.
- Check the layout on both a phone-sized screen and a computer.
- Replace the sample project descriptions on `gallery.html` with your actual work when available.
- Review the About page and change any details that do not describe you.
- Confirm the repository is public and the GitHub Pages link works.
